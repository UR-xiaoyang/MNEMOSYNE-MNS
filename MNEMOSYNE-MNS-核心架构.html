MEMORY NAVIGATION & SCHEDULING SYSTEM

MNEMOSYNE-MNS 核心架构

把长期记忆变成可检索、可约束、可追踪的 Agent 上下文服务。

运行时 FastAPI · SQLite / FTS5 检索排序 ROUTE → Hybrid RANK → Context Assembly 默认边界 本地优先 · 显式长期写入 · Shadow 可选

当前在线模型

Hybrid E5 + features 是当前推荐 RANK baseline；E5 权重冻结，线上只做编码、特征计算和打分。

为什么不是单一向量检索

E5 捕捉语义相似度；TF-IDF、词项重合、指代/否定/更新 cue 补足精确匹配和上下文信号。

训练证据

验证集为 312 queries、30,069 candidate pairs；Hybrid 的 NDCG@10 = 0.5796，优于 Frozen E5 的 0.5146。

模型边界

scope、authority、validity、egress、version 等系统约束仍由前置硬过滤和上下文装配负责，不由当前 Hybrid 学习。

01在线检索链路

ROUTE 给出路径与权限信号；MemoryStore 先按 scope、身份、egress 和有效性筛选，再由 Hybrid RANK 排序，最后按冲突、重复和 token 预算装配上下文。

02持久化与写入边界

记忆实体和 FTS 索引保存在本地 SQLite。对话回合只形成 session 工作上下文；长期记忆的新增或替换必须通过显式 API，提案接口不会自动提交。

03可观测与模型迭代

Shadow Mode 默认关闭且仅本地记录。trace 可用于离线回放、评估和训练；候选 ranker 经版本化后显式部署，不存在在线自动训练或自动晋升。
