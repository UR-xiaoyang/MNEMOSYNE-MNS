01 · 核心专家图

ROUTE → RETRIEVE / HARD GATE → RANK → ASSEMBLE → INJECT

导航层

ROUTE 给出路径、query kind、authority 与慢回退信号，不负责召回。

记忆层

RETRIEVE 先做 FTS5 / fallback 和硬门控；egress 在这里检查。

决策层

RANK + ASSEMBLE 决定候选顺序与 token-budget 注入集合。

治理层

WRITE / UPDATE / AUDIT 是显式旁路；Shadow 默认关闭且本地化。

系统职责

MNEMOSYNE 负责记忆实体的导航、召回、排序、准入、egress 边界和生命周期；宿主模型负责生成。

会话与长期记忆

每个回合可幂等写入 session working context；它不会自动升级为 project / global 记忆。

安全与反馈

提案不落库，长期写入需显式 API；trace 可用于离线评估，但不在线自训练或自动晋升。

02 · 模型数据流

硬过滤 → 双分支特征 → 13 维融合 → 标准化 → 排序分数 → Top-K

输入与门控

Query / candidate memory 先过确定性硬过滤，再进入学习排序。

双分支编码

冻结 E5 生成语义相似度；结构化分支捕捉 lexical、cue 和长度信号。

融合与打分

1 + 12 = 13 维，经 StandardScaler 后进入成对 Logistic Ranker。

模型边界

ranker 只输出排序分数；冲突、预算、egress 和注入策略由系统规则控制。

当前在线模型

MNEMOSYNE-MNS-RANK-HYBRID-01 是当前推荐路径；E5 权重冻结，线上只做编码、特征计算与评分。

训练证据

验证集 312 queries、30,069 candidate pairs；Hybrid NDCG@10 0.5796，高于 Frozen E5 0.5146。

可选基线与边界

服务暴露 hybrid / e5 / tree 可选模型；scope、authority、validity、egress 不由当前 Hybrid 学习。
