MEMORY NAVIGATION & SCHEDULING SYSTEM · ARCHITECTURE / V2

MNEMOSYNE-MNS 核心架构

把长期记忆变成可路由、可过滤、可排序、可约束、可审计的 Agent 上下文。

这不是一个单一向量库核心是专家模块协同：ROUTE 决策、RETRIEVE 召回、RANK 学习排序、ASSEMBLE 控制注入，写入与观测保持显式边界。
在线主链路 ROUTE → RETRIEVE / HARD GATE → RANK → ASSEMBLE → INJECT当前模型 RANK-HYBRID-01存储 MemoryEntity + SQLite / FTS5治理 WRITE / UPDATE / CONFLICT / AUDIT

01 / CORE EXPERT GRAPH · ONLINE RUNTIME

宿主 Agent 只负责生成；MNEMOSYNE 负责记忆导航、准入与生命周期

导航层

ROUTE 不负责召回；它给出分类路径、权威需求与慢回退信号。

记忆层

RETRIEVE 先从实体库召回，MemoryEntity 的 scope / egress / validity 是硬边界。

决策层

RANK + ASSEMBLE 负责“选什么”和“能否注入”；EGRESS 在 RETRIEVE 硬门控中检查。

治理层

WRITE / UPDATE / AUDIT 都是显式旁路，在线生成不会隐式改变长期记忆。

02 / MODEL INTERNALS · RANK-HYBRID-01

1 个 E5 语义特征 + 12 个结构化特征 → 13 维输入 → Logistic Ranker

输入与门控

Query / candidate memory 先过确定性硬过滤，再进入学习排序。

双分支编码

冻结 E5 生成语义相似度；结构化分支捕捉 lexical、cue 与格式信号。

融合与打分

1 + 12 = 13 维，经 StandardScaler 后进入成对 Logistic Ranker。

线上边界

模型只输出排序分数；冲突、预算、egress 和注入策略由系统规则控制。
