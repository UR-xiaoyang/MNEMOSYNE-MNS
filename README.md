# MNEMOSYNE-MNS

MNEMOSYNE-MNS（Memory Navigation Scheduler）是一个可插拔的外置记忆导航与调度系统。

## 设计目标

- 用外部记忆实体库承载长期记忆；
- 通过分类树、快速索引和慢速索引完成分层召回；
- 组合可独立训练、版本化和替换的专家模型；
- 在作用域、权限、版本和 token 预算约束下装配上下文；
- 保留完整 trace，支持回放、评估和持续训练。

## 专家模块

```text
ROUTE       查询路由
WRITE       记忆提取
UPDATE      记忆更新
RETRIEVE    多路召回
RANK        候选重排序
CONFLICT    冲突检测
ASSEMBLE    上下文装配
AUDIT       后台审计
EGRESS      本地/云端投递策略
```

## 仓库边界

本仓库只保存：

- 训练和推理代码；
- 配置与 schema；
- 测试；
- 架构和实验文档；
- 可复现的构建脚本。

以下内容**不进入 Git 仓库**：

- 私有对话数据集；
- Claude、Codex、OpenCode、Hermes 原始历史；
- 数据库、日志和本地 agent 状态；
- 训练缓存和实验输出；
- 模型权重。

模型权重计划单独发布到 Hugging Face，并在对应模型卡中记录训练数据范围、许可证和限制。
